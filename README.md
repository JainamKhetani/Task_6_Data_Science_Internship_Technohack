# ⚙️ 6. Statistical Analysis Workflow

The following analysis steps were performed:

### 🔹 Step 1: Dataset Loading
Loaded the cleaned dataset into the notebook environment using Pandas.

---

### 🔹 Step 2: Dataset Inspection
Checked:
- dataset structure
- data types
- missing values
- numerical columns

---

### 🔹 Step 3: Correlation Analysis
Performed correlation analysis between important numerical features such as:
- retail price
- discounted price
- product rating
- discount percentage

A correlation heatmap was created to visualize relationships between variables.

---

### 🔹 Step 4: Hypothesis Testing
Performed statistical hypothesis testing to compare product pricing and discount patterns.

This helped understand whether significant differences existed between selected product groups.

---

### 🔹 Step 5: Outlier Detection
Used the IQR method to identify unusual or extreme retail prices in the dataset.

This analysis helped detect:
- premium products
- unusually priced items
- pricing anomalies

---

### 🔹 Step 6: Distribution Analysis
Analyzed retail price distribution using:
- histogram plots
- skewness
- kurtosis

This helped understand:
- pricing concentration
- data spread
- distribution behavior

---

### 🔹 Step 7: ANOVA Testing
Performed ANOVA testing on selected brands to compare discount patterns across multiple product groups.

This analysis helped identify variations in discount strategies among brands.

---

### 🔹 Step 8: Statistical Visualization
Generated multiple visualizations for better understanding of statistical findings.
